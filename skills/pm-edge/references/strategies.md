# 通用预测市场：类别方法与条件挂单

这一份管天气以外的事件。天气请配合 `weather.md`。

## 一、所有类别共用的判断顺序

1. **对象是否被唯一确定**：谁/什么、截至哪一刻（写清时区）、YES 的成立条件。涉及"发布""官宣""上榜"的，必须写清指定发布方与页面。
2. **指定来源能否被独立读取**：计数看指定账号/追踪器；票房看指定统计机构；奖项看主办方结果页；体育看官方赛果与是否含加时/点球。
3. **当前进度**：已经发生了多少？还剩多少时间/场次？把"当前累计"和"剩余时间"分开写，不要用线性外推冒充概率。
4. **基准率**：同类事件历史上多久发生一次。没有同类历史就写"判断，不是统计"。
5. **成本**：本侧真实 ask（或等份配对的两条 ask）、费用口径、数量能否一次成交。
6. **失效条件**：什么会让判断立刻作废（数据源改口径、赛程变更、候选退选、计数口径调整）。

## 二、计数类（推文、发帖、观看量）

- 先确认计数口径：是否含转推/引用、是否去重、是否统计回复、时区边界。
- 剩余时间占比高时，当前速度的样本很短；用"最近 24h 速度 × 剩余小时"只作情景，同时给出速度减半/加倍的区间。
- 平台限流、活动结束、批量删除都会让速度突变，写进失效条件。
- 典型错误：用累计值直接除以已过天数再乘总天数，忽略事件期的脉冲。

## 三、文化、奖项、票房

- 奖项：评审制与投票制的可预测性完全不同；评审制看评审构成与历史偏好，投票制看民调/赔率共识但注意样本自选择。
- 票房：首周末预测误差大，第二周衰减曲线更可建模；档期竞争、银幕数、口碑评分是主要变量。
- 榜单/提名：注意"是否已官宣"与"泄露名单"的区别，后者不能当结算源。

## 四、体育与赛程

- 结算常含"加时/点球是否计入""比赛是否须完成""改期如何处理"，逐条读。
- 淘汰赛的晋级概率与单场胜率不是一回事。
- 伤病/轮换信息时效性极强，报价快照必须带时间。

## 五、政治与宏观

- 基准率（在位者连任率、民调误差分布）优先于单条新闻。
- 民调聚合的误差在临近选举时仍然很大；不要把单一民调当概率。
- 结算源通常是官方公告，注意"何时算正式生效"。

## 六、条件挂单（"挂远一点"）

用户说"挂远一点"，先按**价格**理解：低于当前 ask 若干 tick 的被动买单。写法：

```
方向：买 YES/NO
现价可成交：0.42（本侧 ask，20 份一次成交）
等待限价：0.38（低于 ask 4 个 tick，tick=0.01）
失效：报价回到 0.42 以上仍想买 → 重新评估；目标日开盘前未成交即撤
```

- 限价单不保证成交，也不保证 maker 费率；未成交就是不成交。
- 限价成交意味着"市场在你挂单期间变得更便宜"，往往因为新信息出现——成交后要重读证据，而不是庆祝捡便宜。
- 低价不等于高胜率：价格低只提高赔率，胜率仍取决于事件本身。
- 另一个"远"是天气档位离预报中心远，那属于 `weather.md` 的压力测试，和价格距离不是一回事，表里分列。

## 七、盘口占比怎么读

`pm_common.analyze_books` 输出两个比例：

- **卖盘 NO 占比** = NO 侧 ask 2¢ 内美元深度 /（YES ask + NO ask）。表示愿意卖出 NO 的挂单供给占比。
- **买盘 NO 占比** = NO 侧 bid 2¢ 内美元深度 /（YES bid + NO bid）。表示挂着买入 NO 的流动性占比。

两者都只是挂单量，**不是交易人数、持仓比例、信心或事件概率**。单次快照也不能证明动量；要谈情绪变化必须对比两次不同时间的快照，并注明时间戳。

## 八、等份 YES+NO 的价差观察

只有在下列条件同时满足时，才把"两腿成本 < 1"写成条件价差：

1. 两侧都按 **ASK** 买入（不是 YES bid + NO ask）；
2. **等份数**，且两条 ask 阶梯都能完整成交（`complete=True`）；
3. 费用口径已核实（未知费用只能标"毛价差观察"）；
4. 结算与兑换条件一致（同一市场、同一结算源、可合并/赎回）。

即便算术为正，两腿也不是原子成交：先成交一腿、另一腿被扫的风险真实存在。不要用"无风险"这个词。

## 九、常见错误

- 用标题猜规则，不读结算条款。
- 用中价、最新成交价、`1 − YES bid` 代替本侧真实 ask。
- 把部分成交的均价当成整笔可成交价。
- 把挂单占比当胜率或"市场情绪概率"。
- 未核实费用就算净边际。
- 用其他平台同名市场的结果代替本平台结算源。
