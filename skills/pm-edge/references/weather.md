# 温度盘的口径与做法

## 一、规则与市场基线

每个合约重新核对以下项目，不能把其他日期、城市或平台的历史口径当作本合约规则：

1. 结算站与标识：机场 ICAO 或指定观测站；香港天文台不是 VHHH 机场。
2. 指定数据源及页面，是否接受代理归档，如何处理数据修订。
3. 目标日期、当地时区、最高温或最低温。
4. 单位、精度、取整与档位边界；香港 floor、METAR RMK 十分之一度等只有在本合约规则确认后才能采用。
5. SPECI/routine 的取舍、缺失数据兜底、更正与最终结算条件。

发现范围兼顾最高温与最低温，核对市场高概率侧，不只接收扫描器高模型边际或 NO 候选。对所查事件查看完整温度档位的市场分布与独立预测分布，同时评价各档 YES/NO；记录同一时点 bid/ask、价差及计划份数的完整执行成本，比较当前费用后条件价值。缺档、缺侧、缺来源或未覆盖的最高/最低温范围须列明，不能据此称市场无机会。ask 是执行成本，不是真实胜率；独立证据用于解释偏离，不采用固定 blend，也不因模型与市场一致就宣称必胜。

## 二、数据源与误差身份

- routine METAR、SPECI 与高频 ASOS 不是同一种观测采样。只能按合约要求选择，不能混用极值或把一种采样的偏差套到另一种结算口径。
- IEM 等代理归档可用于诊断，但不自动等于指定源已核实；边界读数尤其需要回指定源复核。接口覆盖与延迟以当次请求为准。
- 香港 Daily Extract 与官方九天预报分别是结果与预测来源，不可用机场读数代替天文台结果。源未更新就等待，不用代理值代填正式结算。
- HKO 评分容忍区间不等于统计标准差；网格预报与天文台的残差不是官方预报与结算值的误差分布。没有来源、样本定义和可复核事前记录，不引用历史命中率或误差数值。
- 集合成员共享信息，不是独立重复试验；成员比例不是已校准胜率。

## 三、预测与压力情景

扫描统一使用 `pm_weather.py`。脚本中的模式中心、偏差修正、成员比例和漂移计算都必须结合其输出身份解释：

- 未修正与修正结果均为**未验证情景**，不能只挑有利的一组。
- 兼容字段 `p_calibrated` 即使使用正态 CDF 与 σ 下限，也只是平滑分布情景；平滑不等于经验校准。
- 模式一致不证明准确；模式分歧、降水或天气型变化是重估依据，不在文档另设无依据的硬阈值。
- 所有 NO 使用相同压力情景，包含零漂移；中心在所卖档内和相邻档尤其要披露。距离按档位边缘计算，落在档内记零。
- 压力测试是对假设的敏感性分析，不是实际概率，也不是普遍必要或充分的盈利条件。不能因为距中心更远就取消压力检查，也不能为保留某个推荐改变规则；既有脚本漂移幅度、筛选门槛属于研究启发式，不是校准或盈利证明。
- 香港官方预测误差尚未得到适用的样本外验证时，不将网格残差代理包装为官方预报胜率。
- `--risky` 仅展示诊断候选。正式脚本硬筛未通过须明示，不能悄悄绕过或为凑推荐改门槛；独立研究须有额外证据，注明独立研究身份与原筛选失败，不把诊断项改称脚本合格项。

“挂远一点”是更低买入限价，不是选择更远温度档。低价改善条件赔率；成交可能伴随新天气信息，需要重新核对预测与市场。

## 四、当天只能单调排除

最高温的已观测最大值只会增加，最低温的已观测最小值只会降低。只有观测符合指定源、单位和取整规则，且已穿越对应边界时，才可排除被突破档位。

当天尚未结束，不能因为下午没有升温或暂时只剩某档看似可能，就宣布最终档锁定。工具的 `IMPOSSIBLE_ABOVE` / `IMPOSSIBLE_BELOW` / `STILL_POSSIBLE` 是条件诊断，不是正式结算或必胜保证。观测修订、缺测与规则兜底仍须考虑。

## 五、事前快照与可信结算

- 保留扫描时的预测来源、预测发布时间、抓取时点、目标当地日、站点/坐标、方向、单位和模型身份。历史缓存要核对版本与请求映射，不能从错配缓存取证。
- 预测快照追加保存，便于追溯；**追加记录不是防篡改保障**，不能声称账本不可修改。
- 不用后来的预报、实况或重建缓存补造当时预测。缺少有效事前中心的记录可以核对结果，不能进入预测偏差或概率验证。
- `--settle` 要求当地日结束，但这只是必要条件。指定源尚未核实的结果为 `pending_source_verification`，不得进入可信命中率、Brier 或其他校准统计。
- 代理观测不是指定源的替代证明。只有指定源发布且核实、预测与结果口径一致、事前证据有效，才能作为可信验证样本；后续修订需保留来源与状态变化。
- 中心命中率、区间覆盖率和交易盈亏是不同指标，不能互相替代。测试通过也不证明情景概率是真实胜率。

## 六、执行与复查

- 读本侧真实订单簿，按计划份数走完整阶梯；未知费用不填零，部分成交均价不当全额成本。
- 盘口深度仅描述执行容量，不能支持方向信心；薄盘也不是更信模型的理由。
- 事件更新、当地日进展、指定源修订或挂单成交时重新核对证据，写明失效条件，不保证止损或撤单能够成交。有过跟踪方向时，交代旧时点及依据、新证据和变化；只有实质新证据支持才更新方向，候选排名变化不是反向信号。旧价注明到期或失效，证据不足可暂停，不以旧报价继续推荐。
- 主表只列当前可考虑或有证据支持的限价等待；不参与与纯观察单列。报告实际检查的城市、日期、最高/最低、档位及两侧覆盖和缺失，结论限定于该范围。
- 等份 YES+NO 只有两侧 ask 足额、费用和兑换条件均核实才讨论条件价差，仍有非原子单腿风险，见 `mechanics.md`。
