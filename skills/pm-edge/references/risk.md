# 概率、仓位与风险

## 一、市场基线与独立概率

报价作为市场基线：同一时点记录 bid/ask、价差与深度，但 ask 是执行成本，不是真实概率。独立证据必须说明相对市场偏离的理由，不能把市场报价抄成独立预测，也不预设市场一定正确。

- 有基准率就说明来源、样本与适用性；没有就写“判断，不是统计”。
- 概率区间说明推导方法及不确定性，不能无依据宣称置信水平或给精确胜率。
- 拆分必要条件时考虑相关性；多个同源模型一致不等于多份独立证据。
- 集合比例、正态平滑与漂移结果是未验证情景；`p_calibrated` 字段名不构成校准证明。不采用无来源概率映射或固定 blend。
- 不把报价高、买盘深或低价远档当成高胜率证据。

## 二、单位期望与盈亏平衡

对买入一份二元合约，设 `p` 为获胜概率，`v` 为获胜时每份可得的净兑付（扣除胜出时费用等），`c` 为每份总入场成本（含已核实交易费与按数量计算的滑点）；失败兑付为零：

```
单位期望 = p*v - c
盈亏平衡概率 = c/v
一次盈利 = v-c
一次全损 = c
抵消一次全损所需盈利次数 = ceil(c/(v-c))
```

最后一式要求 `v>c`，描述等成本、等份数且兑付相同的实际盈亏，不是 `c/期望边际`。若 `v<=c`，不存在有限的正盈利次数可抵消全损。退款、部分兑付或退出成交等其他情形需另列现金流。

例如 `v=1, c=0.95`，每次赢赚 0.05，一次输亏 0.95，需要 19 次盈利抵消；`c=0.90` 则需 9 次。高价格不构成高胜率证明，而是抬高盈亏平衡要求。

费用公式以该市场当期规则为准，不能统一假设 `费率*价*(1-价)`，不能把未知费用填零。费用未知只写毛值或有标签的假设情景；未验证 `p` 算出的期望也必须标情景，不宣称已发现正优势。当 `v=1` 时 `p-c` 才是简化的单位期望。

## 三、仓位由风险反推

1. 用户给出本金和风险预算后才算实际金额，没有就只给单位风险示例。
2. 概率证据薄弱、区间跨越盈亏平衡或来源待核实，应等待或不参与，不能用“研究仓”规避证据要求。
3. 按计划份数检查完整订单簿与费用，深度不足就降容量或等待，不把部分成交价当全额价格。
4. 同事件、同结算源、同天气或其他驱动因素归入相关簇，合并风险预算。
5. 到期失败归零时，数量上限为 `风险预算/c`；止损或退出不保证成交，不能当作可靠的全损上限替代。

不为证据不足的模型设置无依据仓位比例，不因前一笔亏损加仓摊平。挂单变便宜可能是新信息导致，成交前后都须核对失效条件。

## 四、验证不是平滑

只对有有效事前预测、同口径结算且指定来源已核实的记录算概率评分：

```
Brier = mean((预测概率 - 实际结果)^2)
相对评分 = 1 - Brier(预测)/Brier(市场基线)
```

市场基线需明确选取方法与时点，不能把 ask 直接叫真实概率；两组用同一结果和匹配样本。基线 Brier 为零时不计算该比值。样本量、事件相关性、选择偏差和不确定性都须报告，不设一个样本数就自动宣布校准。

- 当地日结束只是必要条件；`pending_source_verification` 不进入可信统计。
- 缺少有效事前预测、来源或时点的记录不用于验证，不能事后重建成样本外预测。
- 按适当的城市、方向、单位、预测提前量和模型版本区分；中心命中率不是交易胜率，也不是概率校准。
- 保存当时的市场基线、理由与未参与记录，避免只记赢家。
- 预测快照追加保存不是防篡改保障。来源核对和事前记录要求不能因此省略。
