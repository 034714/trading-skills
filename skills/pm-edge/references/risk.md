# 概率、仓位与风险

## 一、概率怎么写

- 先写基准率：同类事件历史上多久发生一次？样本多大？
- 再分解：把事件拆成必要条件，逐项写概率，注意相关性。
- 没有基准率时，明确写"这是判断，不是统计"。
- 给 80% 区间，不给装饰性的 95% 线。区间宽度超过 30pp 时，只做研究仓或不参与。
- 对极端值收缩：没有强证据不要写 <5% 或 >95%。

市场价不是先验。看到价格之后再"修正"自己的估计，通常只是把市场价抄一遍。

## 二、净边际与盈亏平衡

```
净成本 = 可成交价 + 费率 × 价 × (1 − 价)
净边际 = 你的概率 − 净成本
盈亏平衡概率 = 净成本
```

含义：你要在 0.95 买入，就必须真的相信 95% 以上。**高价格本身不构成高胜率**，它只是要求你更准。

一次归零要多少次盈利才能抵消：`净成本 / 净边际`。0.95 买入、5pp 边际，需要 19 次；0.90 买入、3pp 边际，需要 30 次。所以微小边际配高价格是最脆的组合。

## 三、仓位：由风险反推

没有固定比例可以照搬，按这几轮收缩：

1. **风险预算**：单笔可承受亏损是账户的多少？0.5–2% 是常见区间，不是定律。
2. **区间宽度**：区间越宽越收缩；区间下界低于净成本 → 研究仓或不参与。
3. **深度**：2¢ 内能吃掉多少就是上限，吃不进就等于没有这个仓位。
4. **相关性**：同一事件、同一结算源、同一驱动因素算一个簇，簇内合并预算。
5. **样本**：自己的校准样本不足 30 条时，从最小仓开始。
6. **尾部**：这笔全损之后还能不能继续做下一笔？不能就缩小。

数量 = 风险预算 / 每份净成本（二元到期归零的情形）。带止损的线性品种另算：数量 = 风险预算 / 止损距离。

金额需要用户给出本金与风险比例。没有这两个数，只给"单位风险"示例（例如每 $100 风险对应多少份），不要假装知道用户的账户规模。

## 四、不要自欺的几种情形

- 因为价格已经 0.95 就觉得"几乎确定"。
- 用多个同源仓位假装分散。
- 用胜率安慰自己：胜率高但每次赚很少、偶尔归零，长期仍可能负。
- 加仓摊平上一笔亏损。
- 把模型概率、预报概率、别人的分析当成"真实概率"。
- 把订单簿挂单占比（买盘/卖盘深度比）当成概率、信心或"市场情绪概率"——它只是挂单量，单次快照连动量都不证明。
- 把"远档 + 低价"当作高胜率：低价只抬高赔率，胜率仍取决于事件与误差结构。
- 把 `--bias` 里几十条样本的中心命中率当作校准过的胜率。

## 五、校准

记录每一次判断（含不参与的），结算后算 Brier：

```
Brier = mean((你的概率 − 实际结果)^2)
```

和市场价比：`skill = 1 − Brier(你) / Brier(市场)`。样本少于 30 条时，把差异当噪音。连续多笔比市场差，就该怀疑流程本身，而不是加大仓位。

只把**当地日已结束、指定来源已发布**的结果计入校准；事后用后来的预报重建"当时的中心"不是样本外预测。摄氏与华氏不能混算，分城市×方向×单位记录。

记录里保留"当时的价格"和"当时的理由"，否则事后无法判断是运气还是判断力。`--settle` 写历史时会带上 `centre_source`；没有扫描时中心的记录只用于核对实际值，不参与偏差统计。
