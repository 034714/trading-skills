# 技术研究：实现与人工核查

## 已实现

- EMA20/50/200使用已完成日线；排列只描述状态，不自动决定多空。
- RSI14用Wilder平滑；完全平盘返回50，不是100。
- ATR14为最近14个真实波幅的简单均值，不是Wilder ATR；日线ATR不应机械作为任意时间尺度止损下限。
- RV用30个日对数收益，年化因子√365，不是未来波动预测。
- 90日高低区间回撤只是区间几何值，并非识别出的有效摆动斐波那契。
- 4H摆点需左右各2根已完成K线，确认有滞后；最新高低不等于BOS或CHOCH。
- 快照字段来自公开接口瞬时数据：现价与24h行情（现货）、资金费率与标记价（`premiumIndex`）、OI及24h变化（1小时粒度加总）、多空比（账户口径，1小时）。任何一项失败只标记unavailable，不影响K线指标；但快照不是趋势分析，也不核验逐笔数据。
- 山寨币扫描（`--scan`）对每个标的只算日线指标与快照费率：RSI阈值30/70、90日区间位置≥95%/≤5%、EMA20>50>200多头或反之空头排列、|费率|≥0.05%/8h 的描述性标记。标记是筛选线索，不是信号；山寨币流动性与上市规格未核查。
- 输出数字按有效位舍入（价格6位、百分比1–2位）仅为可读性与token节省，指标计算全程全精度。
- 本地UTC时间筛掉未收盘K线；拒绝历史不足、间断和明显陈旧的数据。电脑时钟错误仍可能影响结果。

## 未实现，不可冒称完成

没有1H触发、多周期共振评分、BOS、CHOCH、订单块、FVG、流动性扫单识别，也没有回测统计优势。人工判断必须注明来源、周期、K线完成时间、具体价位与失效条件；无法举证则标未确认。

BOS/CHOCH是结构突破的描述，定义必须事先固定。OB并无统一标准，需明确规则和样本。FVG通常描述三根K线的价格不重叠区，不代表没有成交、更不保证回补。扫单后收回只能描述路径，不能证明操纵者意图或风险很小。

多周期冲突应等待或重新明确交易假设，不能凭“更小仓位”把未经验证信号变成可靠信号。整数价、RSI阈值、回踩与放量都不是普适胜率证据。

## 风险计算

用户提供本金与风险预算后，线性成本前数量示意为`预算/|均价-止损|`。费用、滑点、资金费和强平风险须另计。止损不是亏损上限，较宽止损不代表真实风险固定；不能通过缩窄止损来满足杠杆阈值。

分批阶梯（`--tranches`）以入场价为首批、按0.5×ATR14等距向失效价方向排布，等权重；剔除后批次与失效价距离不足25%止损距离的档位。R目标与仓位按全部批次的均价计算，总预算必须覆盖全部批次——分批摊低成本的同时，若失效价触发，所有批次同时亏损。分批不是加信号，只是执行路径。

每个条件方案至少说明入场触发、价格失效与时间有效期，任一未确认时只作研究草案。毛R目标不是盈利预测；负价格目标应舍弃。
