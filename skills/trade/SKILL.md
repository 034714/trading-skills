# trade — 条件方案与行情研究

## 不可跳过的边界

- 默认只读，不下单、不调用私有交易接口，不收集密钥、不读写用户账本。公开发布此技能不代表授权交易。
- **先输出条件挂单卡，再给简短理由**。数据不足时卡片写“等待/研究草案”，不以均线排列替代买卖信号。
- 未知本金、风险预算、持仓与账户计价币时，不假设本金或风险比例，不给可执行仓位。不得擅自修改用户风险上限。
- 均线、ATR、RSI、摆点仅为描述，不提供胜率保证。不能单凭 IV/RV 差额推导便宜、昂贵或买卖优势。
- 止损触发和平仓请求均不保证成交；跳空、滑点、流动性与平台故障可使损失超过预算。名义杠杆不是强平安全距离。
- 不以无证据的固定 3× 阈值拒绝；可使用用户明确设置的风险/杠杆上限。超限应降低风险敞口或等待，**不为满足杠杆而缩窄结构止损**。
- 期权仅展示真实合约候选，不生成可执行卖方组合。中性状态不等于卖波动；不输出裸卖，不用“加保护腿”代替完整风险定义。

## 工作流

1. 明确方向假设、入场触发、失效价、时间有效期、产品类型，以及用户提供的本金与风险预算；缺项就列为待确认，不填造数字。
2. 从技能目录运行 `python scripts/crypto_ctx.py --symbol BTC --json`。无需 API key。只使用 Binance 已完成日线与4H K线；最新已完成日线收盘价**不是实时现价**。本地时钟需准确。
3. 脚本提供 EMA20/50/200、Wilder RSI14、简单均值 ATR14、30日对数收益年化 RV、90日区间回撤和经右侧两根K线确认的4H摆点。`--auto` 按均线状态生成条件情景：以已完成日线收盘作为参考入场，结构位与1.3×ATR取更远止损，列1R/2R/3R与每100美元风险数量示例；震荡列双向备选而非预测。须等待实时价格与完成K线确认，下一根4H结束重审。
4. 多周期共振、1H 入场、BOS/CHOCH/OB/FVG/扫单、新闻、资金费率及OI趋势分析**未自动实现**。如需人工补充，按 `references/technical.md` 和 `references/news.md` 核验并记录来源、时间、证据。无搜索/浏览器工具时明确“未核查”，不能声称已经联网研究事件或新闻。API行情查询不等于新闻核查。
5. 用户已给方向、入场与止损时，可用 `--bias long --entry <价格> --stop <失效价>` 计算毛收益R目标；加用户明确给定的 `--equity <本金> --risk-pct <百分比>` 才有仓位示意。尖括号是占位符，运行前替换。`--max-leverage <上限>` 可选，不设置则不隐含固定上限。
6. 线性数量示意为 `本金×风险比例/止损距离`，不含费用、滑点与资金费；不是最大亏损保证，也不适用于反向合约或期权。落地前按产品乘数、最小下单单位、账户抵押与强平规则重新计算；成本未知时不标可执行。
7. 期权候选限定 `--min-days` 与 `--max-days`（默认3至45天，筛选配置不是普适投资期限）；按最早期限展示最多三个，不按全链最大OI选跨年。`--expiry-hint <DDMMMYY>` 必须在链上且在期限范围内，否则报错，绝不换约。无合约时留空，不放宽期限。
8. 期权规格、结算币、乘数、保证金与深度未核验，全部候选只能用于研究。读 `references/options.md`；不输出USD线性最大亏损、不把mid当成本，不以报价或OI推断必然可成交。

## 条件挂单卡模板

- 状态：等待 / 条件研究草案（非自动订单）
- 标的与产品：标的、交易所、线性/反向等；未确认则注明
- 数据时间：行情抓取时间、最新已完成K线时间；实时报价待核验
- 方向与触发：用户假设；明确价格/结构触发及有效期，缺失则等待
- 入场 / 止损触发 / 失效时间：条件值，不承诺成交
- 仓位：未提供本金或预算则“待确认”；否则仅列成本前线性估算与假设
- 目标：毛1R/2R/3R；负价格目标无效，费用后R另算
- 风险：跳空、费用、流动性、强平及事件未核查项
- 期权：候选或“暂无”，非交易腿、非可执行组合

随后用2–4句说明证据、缺失核查和等待条件。不要先输出长篇行情综述再给卡。

## 错误与验证

- `--json` 成功输出单个含卡片的JSON对象；失败输出单个error对象并以状态码2退出。不要混入进度文字。
- 无效/非有限数、错向止损、过期/越界指定expiry、缺少已完成历史、数据过旧或有缺口：不出方案。
- 期权接口失败可保留行情研究并标unavailable；指定expiry无法核实则整份失败，不静默回退。
- 离线回归：`python -B -m unittest discover -s tests -v`。测试不调用网络、不访问账户。
