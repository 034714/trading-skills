# stock — Gate 股票永续条件研究

## 不可跳过的边界

- 默认只读，不下单、不调用私有接口，不收集密钥。Gate 美股 16×5 实盘通道与任何券商实盘不在本技能范围。
- 股票永续 24/7 交易，但底层股票有开闭市：**闭市与周末没有撮合锚定**，标记价靠指数锚加情绪定价，开盘跳空可使止损失效；回复时必须带美股时段状态。
- 仅有 Gate 定价的标的（长鑫/宇树/智谱/OpenAI 等）是**单一价格发现场所**：历史短、无外部锚定，指标自动降级（EMA200 缺失会明说），不得当作长周期结构证据。
- 财报与分红日历未自动获取：谈任何计划前必须人工核查标的财报日并注明来源；财报周默认收紧或等待。
- 资金费率按小时结算（以合约 funding_interval 为准）；溢价、OI、多空账户数均为描述性状态，不是信号或胜率证据。
- 未知本金与风险预算不给可执行仓位；合约乘数、最小下单量、强平与退市规则未核验，仓位示意仅为线性估算。止损不保证成交。

## 工作流

1. 明确标的；不知道合约名先 `python scripts/stock_ctx.py --list [过滤词]`。**本技能无默认标的**，`--symbols` 必填（最多 4 个，如 `--symbols CXMT,UNITREE,ZHIPU`）。
2. **一条命令拿全量**：`python scripts/stock_ctx.py --symbols CXMT,NVDA --json`。输出含：Gate 执行快照（标记价/指数锚/溢价/资金费率与周期/OI 名义/多空账户数/杠杆上限/费用/上市时间/熔断状态）、底层信息（美股主上市=Yahoo USD 长历史；0100.HK 等非美元底层仅作背景；无底层明示单一场所）、指标层（美股优先 Yahoo，否则 Gate 永续日线降级）、1H 多周期（source 标注 yahoo=仅正股时段 / gate=24/7）、4H 摆点、美股时段状态、条件卡。**不要再为现价、费率或 OI 另写临时脚本**。
3. 回复格式沿用「结论说人话」：第一句大白话结论（现在做什么+关键价位），卡片表，然后 3–6 句综合建议——多空两边证据、财报核查状态、两个条件分支（跌破 X / 涨过 Y）、「不动也是一种建议」。数字带参照物，指标首次出现给白话注解。周末/闭市时结论必须点明"现在是情绪定价时段"。
4. 持仓复查（如"我有长鑫多单"）：用标记价对比用户持仓均价给浮盈距离；资金费率×预计持有时间估算成本；4H 摆点给减仓/加仓参考位；财报日未核查前列为待确认，不下"继续拿"的结论。
5. `--bias long|short --entry --stop`、`--tranches`（默认3，1–5）、`--equity --risk-pct`、`--max-leverage`、`--auto` 语义与 trade 相同：分批按 0.5×ATR 间隔、距失效价过近的批次剔除、R 目标按均价、总预算覆盖全部批次。日内条件卡有效期到下一根 4H 收盘。
6. 人工补充（财报日、公告、IPO 进展、新闻）必须联网核验并记录来源与时间；无搜索工具时明确"未核查"。API 行情查询不等于新闻核查。

## 条件挂单卡模板

- 状态 / 标的与合约（如 ZHIPU_USDT）/ 数据时间与美股时段
- 方向与触发 / 入场 / 止损失效价 / 分批 / 毛 1R/2R/3R / 仓位（待确认或线性示意）
- **本技能特有行**：标记价 vs 指数锚溢价、底层锚定状态（Yahoo/单一场所）、财报日核查状态、熔断开关

## 错误与验证

- `--json` 成功输出 `stock_ctx_v1` 信封（`symbols[]`、`shared_warnings[]`、`partial_failures`?），紧凑单行；失败输出单个 error 对象并以状态码 2 退出。
- 合约不存在、非股票类（contract_type≠stocks）、两层日线都不足 15 根：该标的进 `partial_failures`；全部失败才整份失败。Yahoo 失败自动退回 Gate 层并写 warning，不静默。
- 离线回归：`python -B -m unittest discover -s tests -v`。测试不联网、不访问账户。
