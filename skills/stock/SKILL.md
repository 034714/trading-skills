# stock — Gate 股票永续条件研究

## 边界

- 默认只读，不下单、不访问私有接口、不收集密钥；保持 stock 名称。
- 不硬编码历史持仓或固定推荐名单。脚本无默认标的不等于必须反问用户：开放式找机会先主动筛选，真正缺少决定性偏好或风险预算时再问。
- 永续 24/7，但底层有交易时段。闭市/周末是情绪定价时段，开盘与财报跳空能击穿止损；香港/韩国标的需另查当地市场日历，美股时钟不是其交易状态。
- 无已验证底层的合约是单一场所定价、短历史，不当作真实未上市公司估值或长周期结构。代码映射是底层身份信息，不是推荐名单。
- 资金费率周期一律取该合约 `funding_interval` 秒，不能预设每小时或8小时。OI名义持仓、24h成交额和多空账户数不等于盘口深度或方向信号。
- 未知本金和风险预算不给可执行仓位；乘数、最小张数、强平、退市、费用与深度需逐合约核验。杠杆上限不是建议杠杆；止损不保证成交，不能靠缩止损满足杠杆约束。

## 工作流

1. **发现与选择**：已指定标的先核对合约；未指定则先 `python -B scripts/stock_ctx.py --list --sort volume --top 12 --json`，有需要加 `--min-volume 1000000 --underlying-only`。默认 `--list` 返回全部，不再截到120行；`count` 是过滤后总数，`returned_count` 是实际返回数。先剔除非交易/退市合约，再用成交量级、底层映射、历史完整性与新闻可核查性挑最多4个深看，说明选择/排除原因。不要把成交额排序叫深度或盈利排名。成交额缺失会明示，不视为零；无合格标的可以不推荐。
2. **行情一条命令**：`python -B scripts/stock_ctx.py --symbols AAPL,NVDA --json`（仅命令示例，非默认推荐）。读取 Gate执行层、Yahoo底层、日线指标、4H/1H状态与摆点、`data_quality`、时段和条件卡。不要另写一次性行情探针，不批量请求全市场K线。`stock_ctx_v1` 原字段保持，新字段为补充。
3. **联网事件研究**：行情后、形成结论前按下方清单实际联网核查。API报价不等于查过新闻。无联网能力/403且无替代证据/信息冲突时明确“未核查/待确认”，不能说无事件。不要为此强接不可靠新闻API。
4. **多周期解释**：日线给大背景与多日假设（通常数个交易日到数周，须另查日线结构）；4H给执行结构和障碍（通常日内到数日）；1H给已完成K线的触发观察（日内，数小时）。这不是自动持有期预测。Yahoo仅正股时段，Gate为24/7；不同源的价格/ATR不能直接拼成共振。冲突、陈旧或缺失则等待，不用缩仓假装消除证据缺口。
5. **目标与周期**：先定方向、触发、失效、持有期，再列结构目标及依据。脚本 `structural_targets` 是左右各2根完成4H K线确认的历史摆点候选障碍（有滞后，不是已识别BOS/CHOCH）；引用时带源、摆点时间、确认规则。没有可举证结构目标就写无法确认，不事后补整数。`gross_R_targets` 是按全部批次均价和止损算的成本前1R/2R/3R，单列，绝不当结构预测或保证可达。目标须写预计观察周期而非保证到达日期。
6. **卡片与复核**：每卡列触发（如完成1H收盘站上某已举证价位后回踩守住）、入场参考、价格失效、结构目标、R目标、持有期、事件避让与时间到期。脚本触发默认 unconfirmed，自动卡仅算术草案，不声称已发生突破。日内草案到下一根UTC 4H收盘重审；新财报、重大公告、结构失效、数据过期或锚定异常可提前作废。多日计划需人工补日线结构与事件窗口，到期与持有期分开。
7. **用户持仓**：只在用户主动给持仓时对比均价；按费率×预计结算次数给常数费率成本示意（实际费率/名义金额会变），不承诺继续持有安全。预算缺失保留待确认。

## 新闻、宏观局势与财报（人工联网必做）

- 同时覆盖公司与行业新闻（至少最近72小时并回看最近重要公告）、持有期内财报/分红/拆股、宏观与地缘局势（央行、通胀、就业、制裁/关税、出口管制、冲突）。按标的经济暴露解释关联，不把所有局势新闻都当驱动。
- 官方优先：公司IR、监管披露（SEC/交易所公告）、交易所日历、央行/统计机构。可靠通讯社/财经媒体交叉核对；403/401换官方镜像、监管披露或其他可靠媒体，记录失败和缺口，不靠标题截图。未经核实社交传闻单独标记。
- 每条关键证据记：事实原文摘要、URL、来源、**发布时间、事件实际/预计发生时间、查询时间**，全部带日期与时区；未知时间写未知，区分财报盘前/盘后、预计与公司已确认。旧报道不冒充新事件。
- 财报检查最近已发布季度及下一次日程：营收/EPS/指引如引用须给口径、期间及原始来源，预期值另给可靠一致预期来源与时间。查不到不造数，不把上一季度时间顺延成确定日期；无公开财报/日程的未上市标的写未知或不适用及理由。
- 输出分开 **事实 → 解读 → 条件情景**。新闻是否已定价不可由单次涨跌断言；“利好”也可能因预期过高下跌。事件未核查不升级卡片为可执行，财报周不机械减半/缩止损，优先等待或明确跳空情景。

## 回复结构

第一句用大白话说现在做什么及关键条件，不强行给交易。开放式筛选先给候选/排除原因，再给简表：

| 标的/选择依据 | 事实/新闻来源与三种时间 | 日线/4H/1H与数据时间 | 入场触发/失效 | 结构目标及依据/观察周期 | 毛R目标 | 到期/风险 |
|---|---|---|---|---|---|---|

补3–6句综合判断：多空证据、宏观/财报缺口、涨破/跌破两种分支以及“不动也是建议”。带标记价vs指数溢价、底层锚定、费率及实际周期、时段与熔断状态。指标首次出现用白话解释；非美元底层不可直接算美元溢价。

## 脚本与验证边界

- `--bias long|short --entry --stop`、`--tranches`（1–5，默认3）、`--equity --risk-pct`、`--max-leverage`、`--auto` 保持原语义。0.5×日线ATR阶梯仅算术示例，不是任意持有期的止损规则；总预算覆盖全部批次。
- Yahoo US日线按16:00纽约时间完成；1H最后一根15:30–16:00仅30分钟。DST按实际切换UTC小时处理。**尚未集成假期/提前收盘日历**，`us_equity_session` 是工作日时钟估计，不是已确认开市；节假日/提前收盘须查交易所，不能冒称自动识别。
- `data_quality` 带源K线起止、年龄、过期标记；Yahoo按工作日时钟检查，异常可因假期，不可静默当新鲜。Gate连续时钟超1.5个周期标陈旧；无K线标unavailable。查询时间不等于源行情时间，Yahoo底层价另看 `price_time_unix`（缺失为未知）。
- `event_research` 默认 not_checked，代表脚本未做新闻研究，不代表助手联网后仍未查。回答中的人工核查应另列证据，不修改行情事实。
- 无合约/非股票/两层日线不足15根进 `partial_failures`；全部失败状态码2。Yahoo不可用自动回退并警告。
- 离线回归 `python -B -m unittest discover -s tests -v`，不联网、不访问账户。测试文件含3个真实提示的规则评估，不等于fresh会话模型效果评测。
