# Trading Skills

面向 AI 助手的两个只读交易研究技能。输出条件化计划，不自动交易，也不保证收益。

- **pm-edge**：预测市场研究，优先天气与文化；明确事件日期，比较 YES / NO，先审计结算规则，再核对报价与费用。
- **trade**：BTC / ETH（可扩展到其他币）技术与期权研究；一条命令带现价、资金费率、OI、多空比快照与山寨币筛选；区分行情快照、模型假设和可执行条件，不把指标或历史波动率比较直接当作买卖信号。

## 安装

将 `skills/pm-edge` 和 `skills/trade` 复制到助手支持的 skill 目录。在 MiMo Desktop 中可使用 `~/.config/mimocode/skills/`；通过插件页面确认已发现技能。不要同时安装同名的多份副本。

## 怎么问

- `/pm-edge 扫描明天的天气盘，给我高胜率的 NO 机会。`
- `/pm-edge 只看纽约、东京、香港。`
- `/trade BTC、ETH 现在什么结构？我想 79500 接多、止损 77800，给分批计划和期权适配。`
- `/trade 顺带扫一下山寨币有什么值得细看的。`

## 天气温盘：问一句，回一张可执行的表

问「扫描明天的高胜率天气盘」，回答长这样（真实输出节选）：

> **买 NO｜高胜率，赌这一档不会中**
>
> | 城市 | 市场 | 档位 | 模型给的胜率 | 买入价 | 赔率 | 便宜多少 | 抗漂移胜率 | 盘口深度 | 依据 |
> |---|---|---|---|---|---|---|---|---|---|
> | 马德里 | 最低温 | 5°C 距中心2.7档 | 94% | 0.76 | 0.32:1 | +18pp | 94%（最坏49%） | $123 | 三模式中心 6-8C，分歧 1.4 |

读法三句话：

- **便宜多少** = 模型胜率 − 买入价，这张表按它排序；不足 5pp 的档不会出现。
- **距中心 X 档** = 档位离预报中心多远。≤1 档的「贴脸档」一次普通预报误差就翻车，默认标 ⚠ 过滤。
- **抗漂移胜率** = 假设预报整体偏 1.5°C 朝这档漂移后还剩的胜率，是 NO 单的安全垫。

背后自动做的事：结算口径对齐官方（美国/欧洲 routine METAR；香港天文台摘录，31.9°C 算 31°C 档）；三模式集合成员 + 各自滚动偏差修正；真实 YES/NO 订单簿报价与深度校验；每天结算昨天并把偏差攒进校准历史。

想直接跑脚本：

```bash
python skills/pm-edge/scripts/pm_weather.py --date 2026-10-26 --top 10   # 扫明天
python skills/pm-edge/scripts/pm_weather.py --settle 2026-10-25          # 结算昨天
python skills/pm-edge/scripts/pm_weather.py --bias                      # 累计校准回测
```

## trade：一句话出 BTC/ETH 全景

问「BTC、ETH 什么结构」，回答开头是一张「现在的位置」快照——现价、已跌破/踩着的关键位、上方面对的阻力、资金费率、多空比、OI、临近事件，一眼看清处境：

<img width="1153" height="751" alt="回答开头的「现在的位置」快照表" src="https://github.com/user-attachments/assets/fdd41015-a990-4821-9278-17de0a653367" />

快照之后是结构判断和条件计划：

- **结构判断**：日线指标 + 4H 摆点，顺势/区间/转折写清依据
- **分批阶梯**：给入场价和止损后，批次按 0.5×ATR 排布、距止损太近的自动剔除，R 目标按均价算
- **期权适配**：最近到期 ATM IV 与 30 日 RV 的比较，只说贵不贵，不说该不该买
- 加一句「扫一下山寨币」会追加 8 个主流币的「值得细看」名单

哪项数据拉不到会明说，不填数。想直接跑脚本：

```bash
python skills/trade/scripts/crypto_ctx.py --json            # BTC+ETH 全景
python skills/trade/scripts/crypto_ctx.py --json --scan     # 加山寨币筛选
```

## 重要边界

- 高市场价格不等于已校准的高胜率；不同模型也可能高度相关。
- 当天最高温和最低温在当天结束之前仍可能改变；观测站、日期、精度和修订规则必须匹配合约。
- 未核实的费用、NO 侧报价、深度或期权结算规格，不能用于声称存在可执行套利。
- 限价不保证成交或 maker 身份；止损不保证成交价。部分成交、滑点、跳空和结算争议都可能造成损失。
- 报价快照和条件计划不是实时指令。没有资金规模与风险预算时，不输出假装适合用户的实际数量。
- 数据接口失败时必须报告缺失，不能填造价格。
- 不包含自动下单、账户密钥、个人账本或对话记录。

## 验证范围

离线回归测试验证公式边界、日期处理和失败路径，不代表已回测出盈利策略；公开接口冒烟测试只说明当时能读到数据，不证明模型准确。历史上的实盘教训（预报漂移击穿相邻档 NO 等）已转化为扫描器的内置风控门槛，但过往验证不构成对未来胜率的保证。使用前应查阅对应平台官方文件和具体合约条款。
